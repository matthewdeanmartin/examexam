START IN YOUR TERMINAL

A few commands.
A full study loop.

Install the CLI, initialize a project, then create a bank from your own topic file. The sample topics below give you a starting point.

Read the full walkthrough ↗
practice-session.sh
# Install and set up
pipx install examexam
examexam init

# Draft and review your question bank
examexam generate --toc-file topics.txt \
  --output-file exam.toml -n 5 \
  --model-provider openai
examexam validate --question-file exam.toml \
  --model-provider anthropic

# Take the exam
examexam take --question-file exam.toml
